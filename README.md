# Phishing Incident Response Playbook & Tabletop Exercise

## Project Overview
This project contains an industry-standard Incident Response (IR) Playbook for handling Phishing attacks, structured around the NIST SP 800-61 framework. It also includes a tabletop simulation exercise conducted to identify process gaps and refine response workflows.

## Contents
- **NIST IR Phases:** Preparation, Detection & Analysis, Containment/Eradication/Recovery, and Post-Incident Review.
- **Tabletop Scenario:** Mock investigation of a credential-harvesting phishing email.
- **Gap Remediation:** Process updates made after testing (e.g., verifying 2FA session revivals).
